# 面板重设计 · 设计说明（横竖屏同一套台面仪表）

## 概念
「台面仪表 / bench faceplate」：面板不是卡片拼贴的仪表盘，而是一整块刻字的仪器面板。
结构来自发丝线、左右两条对齐轨（左标签 / 右读数）和逐页唯一的主读数，而不是一圈圈圆角卡片。
颜色只表示状态，不表示装饰：整张面板是石墨底 + 骨白墨，绿/琥珀/红/蓝只在数值越界时出现。
横屏是这块面板的宽幅版——同一套语法，只是把内容分成三个舱位，而不是另做一套皮肤。

## 令牌
- 深色：底 #08090B · 井 #0E1013 · 轨 #20252A · 发丝 #2A3036 · 墨 #C5CACF · 弱 #828A91 · 主墨 #F4F1EA
- 浅色：底 #E8EAEB · 井 #FAFBFA · 轨 #D9DEDD · 发丝 #CDD3D3 · 墨 #3B4145 · 弱 #646B70 · 主墨 #111416
- 状态：成功绿 / 警告琥珀 / 故障红 / 信息蓝 / 次强调紫（两套主题各自加深或提亮）
- 读数默认是主墨；`lvl-ink` / `tlvl-ink` / `bat-ink` 只在越界时换成警告或故障色
- 选中态 = 底部主墨线（竖屏 3px / 横屏 2px，均压在所在轨道或分段框的下沿），不用实底黑块
- 图表线用强调色，面积填充是强调色的低透明度渐隐
- 旧版装饰性槽位（`card-hi` / `glow-*`）已删除；氛围光斑不再出现在任何一屏

## 字体
- 读数与数字：等宽（设备 Noto Sans Mono CJK SC / 预览 Menlo），表格化对齐
- 标签与正文：Noto Sans CJK SC / 苹方
- 字号阶：7.5 / 8 / 8.5 / 9 / 9.5 / 10.5 / 11 / 12 / 13 / 14 / 15 / 16 / 18 / 24 / 26 / 30 / 34 / 40 / 64 / 72 / 100 / 140
- macOS 预览要跟设备一致：把设备的 `/usr/share/fonts/noto/NotoSansCJK-{Regular,Bold}.ttc`
  装进本机字体库，然后
  `PANEL_FONT_MONO="Noto Sans Mono CJK SC" PANEL_FONT_BODY="Noto Sans CJK SC" cargo run -p device-monitor-panel -- --demo`。
  默认的 Menlo/PingFang 只是本机替代品，字形比设备高一行（见原则 7）。

## 布局（两种朝向共用）
- 一条顶轨 + 一条底轨，中间是连续面板；全屏只有这两条填充横轨
- 分组只用一个「标题 + 延伸到右缘的发丝线」行（`SheetHead`），不画卡片框；
  组间用 1px 发丝线或 16–20px 留白
- 所有位置写成固定坐标，不用会随内容伸缩的布局，避免元素跑偏
- 每页一条主读数，其余读数按「标签 → 数值 → 刻度条 → 副值」重复出秩序
- 图表盒子尺寸写死在 Rust 常量里，Slint 侧必须给同样的宽高（见下表），否则路径会错位

## 竖屏（540×1170）
- 顶栏 0–104（状态灯 + 主机 + 30px 时钟 + 四格页签，选中格下方 102×3px 墨线滑动）
- 内容 104–1096，左右 16 边距，内容宽 508；每页 508×992，页面横移 508（左）/ 256（右）
- 底栏 1096–1170（IP / 收发速率 / 四格页标 / 主题开关，全部垂直居中）
- 每页一条主读数：CPU 48.9% / 今日请求 183 / 时刻 18:21 / 无（设置页）

### 各页节奏（竖屏）
- 系统：CPU 主读数 → 4px 使用率表 → 8 核共享带（126–162）→ 36px 历史条 → 内存/磁盘双表 → GPU+温度 → 5×22 进程表 → 电池主读数 + 6 格读数矩阵 → 网络 → 服务/告警
- Token：183 主读数 + 成功率/费用/缓存率右轨 → Tokens/缓存命中两列 → 508×80 吞吐示波器 → 5 行模型 → 4 行渠道（2px 平均延迟条）→ 三项质量指标 + 508×40 趋势图 → 调用方/网关两列
- 时钟：140px 时刻 + 蓝色秒 → 60 格秒刻度尺 → 天气 + 120px 电池环 → 时间进度四条 → 世界时钟两列 → 日出弧线（固定 420×76 盒）+ 相位条
- 设置：分段轨道（横屏/竖屏/反转、深色/浅色）→ 亮度主读数 + 滑块 → 6 行系统键值 → 电源与连接四个按钮

  - 时钟：x=432、x=772（舱宽 420 / 328 / 370）

- 系统：A 处理器（负载/核心/采集右轨 + 4px 表 + 8 格单核带 + 46px 历史条）→ 显卡·温度（频率 + 表 + 4 行温度）→ 告警行；B 内存/磁盘双表 → 5 行进程表（PID/CPU%/内存/名称）→ 服务标签 2×2；C 电池（64px + 电压/电流/功率 + 6px 表 + 2×3 读数矩阵）→ 网络与无线（SSID/信号/速率/VPN）

## 已删除的旧语汇
`Card`（圆角卡 + 顶部微光）、`Pill`（胶囊标签）、`StatBar`（渐变动画条 + 白色端帽）、
`TabPill`（胶囊页签）、`Dot`（圆点）随两种朝向统一而移除；页面不再引用它们，
避免旧皮肤被重新拼回界面。状态点改用 `LiveDot`（顶栏）或 `SheetHead` 的 `meta-tint` 着色文字。

## 原则
1. 一页只有一个视觉重音（主读数），其余安静。
2. 每个读数同一套语法：标签 → 数值 → 刻度条 → 副值，重复出秩序。
3. 状态色必须有数值同时呈现，颜色只是辅助。
4. 所有位置写成固定坐标，不用会随内容伸缩的布局，避免元素跑偏。
5. 触控目标 ≥ 52 逻辑像素；破坏性操作放页面底部，远离误触。
6. 去掉光斑、渐变洗、入场动画（省 GPU 唤醒，也去掉模板感）；两种朝向同一套皮肤。
7. 大号读数（≥20px）一律显式给 `height` = 字号 + `vertical-alignment: center`。
   字体 ascent 差异（Menlo 0.93em vs Noto Sans CJK 1.16em）会让顶部对齐的字形整体下沉
   近 16px，压到下方刻度条；1em 盒 + 垂直居中把这个偏差压到 3px 内。
